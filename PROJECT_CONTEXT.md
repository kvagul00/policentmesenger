# Полицентр Workspace — контекст для продолжения

Обновлено 21.10.2026.

## Цель

Внутренний мессенджер типографии с обсуждениями заказов. Пользователь хочет продолжать разработку с другого компьютера через GitHub.

## Принятые решения

- Сначала рабочий мессенджер; интеграция базы позже и не блокирует работу.
- В перспективе односторонний импорт Access, Excel и других источников; не записывать обратно в исходные файлы.
- Заказы и статус оплаты доступны сотрудникам. Подтверждает оплату manager; этапы меняет назначенный исполнитель, в прототипе также менеджер.
- Производственные чаты не показывают финансовые суммы.
- unknown/«Не подтверждена» означает отсутствие подтверждения.
- Предоставленная MDB условная. Пользователь разрешил игнорировать проблемы для текущей задачи. Изменения и удаления в MDB не выполнялись.

## Готово

Клиентский прототип: каналы команды, обсуждения заказов, текстовые сообщения, ответы, реакции, поиск, локальные вложения, карточки, этапы и список заказов, создание чатов и экспорт демо-переписки.

Код: dist/. Проверки: domain.test.mjs, docs/QA.md. Пройдены три проверки доменных правил, а также ручные сценарии в браузере.

## Ограничения

Данные — в localStorage конкретного браузера. Общей серверной истории, доставки между ПК, входа сотрудников, серверных прав и объектного хранилища пока нет. Настройки роли демонстрационные, не являются авторизацией. Демо-участники вымышленные.

Клонировать на другом ПК, открыть папку в Codex, прочитать этот документ. Перед началом git pull --ff-only, после работы commit и push.

## Материалы Access

Аудит выполнен read-only на копии, исходник не изменён. MDB и производные материалы аудита сохранены в прежней локальной среде; в этот публичный репозиторий не опубликованы. Публикацию этих материалов остановила автоматическая проверка из-за раскрытия структуры и финансовых агрегатов; для неё нужно отдельное подтверждение пользователя. Для текущей разработки мессенджера эти файлы не нужны.
