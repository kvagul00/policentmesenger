# Работа над Полицентр Workspace

- Сначала прочитайте PROJECT_CONTEXT.md и docs/NEXT_STEPS.md.
- Продолжайте разработку мессенджера; не начинайте повторный аудит MDB без необходимости.
- Текущая версия — клиентский прототип. Не описывайте localStorage, переключатель роли и демо-участников как готовую многопользовательскую систему.
- Основной язык интерфейса и пояснений — русский.
- Не публикуйте MDB, реальную переписку, вложения сотрудников, токены и .env.
- Сохраняйте неизвестную оплату как unknown/«Не подтверждена». Не выводите её из суммы заказа.
- Импорт односторонний, адаптеры не завязаны только на Access.
- Запуск: npm start. Проверки: npm test и npm run check. Зависимостей нет.
- Перед изменением UI исследуйте существующие сценарии. Проверяйте затронутые действия.
- GitHub main — основное место дальнейшей разработки. Не применять force push и не перезаписывать чужие изменения.
- Для работы с опубликованным Sites используйте навык Sites и существующий project_id из .openai/hosting.json. GitHub push не является автоматическим деплоем.
