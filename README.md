# Полицентр Workspace

Рабочий репозиторий проекта мессенджера типографии. Здесь сохранены код прототипа, тесты, требования, результаты аудита Access и контекст для продолжения на другом компьютере.

**Репозиторий:** https://github.com/kvagul00/policentmesenger
**Частный прототип:** https://policentr-workspace-messenger.neatpony6.chatgpt.site
Сайт требует входа через ChatGPT. Доступ к GitHub и доступ к сайту — отдельные учётные записи.

## Продолжить с другого ПК

1. Клонируйте репозиторий:
   ```sh
   git clone https://github.com/kvagul00/policentmesenger.git
   cd policentmesenger
   ```
2. Откройте эту папку в Codex и войдите в свой аккаунт.
3. Прочитайте [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) и [docs/NEXT_STEPS.md](docs/NEXT_STEPS.md).
4. Начните чат с фразы:
   > Продолжаем Полицентр Workspace. Прочитай AGENTS.md, PROJECT_CONTEXT.md и docs/NEXT_STEPS.md. Сначала развиваем рабочий многопользовательский мессенджер; интеграцию Access и Excel откладываем. Текущая версия — прототип в браузере, не выдавай её за готовую серверную систему.

Перед работой на другом ПК выполните git pull --ff-only. После завершения сохраняйте изменения через commit и push. Git переносит файлы и зафиксированные решения; незапушенные изменения и история браузера отдельно не синхронизируются.

## Запуск

Нужен Node.js 18 или новее. Сторонние пакеты не требуются.

```sh
npm start
npm test
npm run check
```

Либо напрямую: node preview.cjs, node --test domain.test.mjs. Сервер выводит локальный адрес с выбранным свободным портом.

## Что уже есть

Чаты команды и заказов, сообщения, ответы, реакции, поиск, локальные вложения, карточки и этапы заказов, создание чатов, список заказов и экспорт демо-переписки.

**Ограничение:** это клиентский прототип на localStorage. Нет общей серверной истории, доставки между компьютерами, входа сотрудников и серверной авторизации. Выбор роли в настройках — демонстрация. Переписка и загруженные в браузер файлы не попадают в Git; для сохранения демо используйте экспорт в настройках.

## Структура

- dist/ — HTML/CSS/JS прототипа.
- domain.test.mjs — проверки правил этапов, оплаты и валидации сообщений.
- preview.cjs — локальный сервер.
- PROJECT_CONTEXT.md — принятые решения и текущий статус.
- docs/ — следующие шаги, проверка, развёртывание и исходное описание прототипа.
- docs/mdb-audit/ — структура Access, агрегаты, обезличенные образцы и маппинг.
- tools/mdb-audit/ — скрипты исследования копии MDB в режиме read-only.
- .openai/hosting.json — идентичность существующего Sites-проекта.

Репозиторий публичный. Оригинальный MDB, его рабочая копия, локальные пути, токены, секреты и пользовательская переписка в него не включены. Аудит и инструкции сохранены; сам MDB понадобится отдельно, когда начнётся интеграция.

Исходники прототипа также сохранены в репозитории Sites. Этот GitHub-репозиторий — основное место дальнейшей совместной разработки. Обычный push в GitHub сам по себе не публикует изменения в Sites.
